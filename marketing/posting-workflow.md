# Posting workflow — Meta Business Suite + TikTok Studio

No API approvals, no monthly fee. You batch the week in one sitting and the
platforms publish on their own.

## Once, to set up

1. **Instagram → Professional account.** Settings → Account type and tools → Switch to
   professional. Pick Business.
2. **Link it to the Facebook Page.** On the Page: Settings → Linked accounts →
   Instagram → Connect. Meta Business Suite only schedules Instagram through a linked
   Page.
3. **Open Meta Business Suite** at business.facebook.com and check both the Page and
   the Instagram account appear in the account switcher.
4. **TikTok:** tiktok.com/tiktokstudio in a desktop browser. TikTok's scheduler is
   web-only — the phone app cannot schedule.

## Every week

1. **Build the posters.** In the studio, queue your screenshots or clips, pick the
   style and layout, write each caption in the **Post caption** box.
2. **Set the plan.** Posting plan group: posts per day, the first post date, and which
   platforms. The slot times are already set for a Malaysian audience —
   12:30 lunch, 18:00 commute, 21:30 evening.
3. **Export queue (ZIP).** You get:
   - the posters, numbered in posting order
   - `posting-plan.txt` — each slot with its date, time and caption, ready to copy
   - `schedule.csv` — the same thing as a spreadsheet, if you'd rather work from one
4. **Meta Business Suite → Create post.** Tick both Instagram and Facebook, drop the
   image in, paste the caption, Schedule, set the date and time from the plan. Repeat
   down the list. Reels schedule the same way.
5. **TikTok Studio → Upload.** Video only — TikTok will not take a still image through
   the web uploader, so a sticker-style poster goes up as its **clip** export, not the
   PNG. Paste the caption, toggle Schedule, set the time. TikTok allows scheduling up
   to **10 days** ahead, so plan TikTok in ten-day blocks even if Meta is set a month out.

## What each platform wants

| | Format from the studio | Note |
| --- | --- | --- |
| Instagram feed | Feed PNG, 1080×1350 | Images must be JPEG if you ever switch to the API; the native uploader takes PNG fine |
| Instagram Reels / Stories | Story MP4, 1080×1920 | Story export already keeps the top and bottom clear of the app's own UI |
| Facebook Page | Feed PNG, or the MP4 | The same post can go to both from one Meta Business Suite composer |
| TikTok | Story or Feed **MP4** | Still images are not accepted by the web uploader. Use Save video |

## Worth knowing

- Posting the identical file to all three every day tends to underperform. TikTok wants
  vertical video that feels native, Instagram rewards Reels, Facebook is where the
  Kaicash and promo posts land best. The studio exports a different format per platform
  for exactly this reason — use them.
- Meta Business Suite schedules between 10 minutes and 30 days ahead.
- Keep the caption's first line strong. Instagram truncates after about two lines in the
  feed, and that is what decides whether anyone taps "more".
- If this ever becomes too much clicking, Buffer at about USD 5 per channel per month
  takes all three from one queue. The `schedule.csv` this export writes is the thing
  you would import.
